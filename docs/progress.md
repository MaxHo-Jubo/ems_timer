## <a id="progress-2026-05-09-2"></a>進度 2 — 2026-05-09 — 補登次數選單列表化＋介面文字溢出修整

### 一句話

把「補登 EPI 幾次」畫面改成**像清單一樣的選單**（之前是大數字 1/2/3/4/5 上下調），同時修了「Amiodarone 已紀錄」提示和子選單底部三段操作提示**文字超出螢幕邊界**的問題。

### 你會看到什麼差異

1. **補登次數變成清單樣式**：長按 EPI → 選「補登 EPI」→ 接手前 / 純補登 → 進入次數畫面，現在顯示 5 列（接手前 ×1～×5）或 3 列（純補登 ×1～×3），上下鍵滑動、主鍵確認，跟線上 demo 完全一致。
2. **Amiodarone 提示完整顯示**：之前確認 Amio 後跳出的「Amiodarone 已紀錄」字太大會切到螢幕外，現在自動縮到剛好。
3. **子選單底部提示重排**：以前「上下選擇　主鍵確認　返回取消」全擠在中間、左右會被切；現在改成**左 / 中 / 右三段分排**，貼邊 10 像素，視覺更清楚也不再溢出。
4. **內部進度標籤對齊現況**：程式碼開頭的階段註解全面重寫，把已落地的補登 / 總覽 / Amio 等子流程標為 ✅；把因升級螢幕而被佔用的腳位（震動馬達讓位給彩色螢幕）也註明清楚。

### 過程中遇到並解決的問題

- 第一次修「Amiodarone 已紀錄」只降一級字仍然爆字 — 增開**更小一級的字級檔位**專供英文+中文混合的長標題使用。
- 補登次數第一版只把大數字下移避免擋到「次數(1~5)」標籤 — PM 回饋「跟 demo 不一樣」，第二版整個改成清單樣式對齊 demo。
- 子選單底部三段提示縮字仍擠 — 改成**三段分別貼左 / 置中 / 貼右**，字級縮 0.85 倍，邊距留 10 像素。
- 程式碼註解一度誤寫「× 改 ASCII x 避免字型缺失」— 實機驗證字型有 ×，且 Amio 確認 / 補登成功畫面也已用 ×，改回 × 並修正註解一致性。
- 線上 demo 主選單原本只能看到 4 個項目（第 5 個「系統設定」被螢幕底邊切掉）— 已修，把每列高度從 48px 縮成 38px，5 項合計 217px 在 240px 螢幕內完整顯示。

## <a id="progress-2026-05-09"></a>進度 1 — 2026-05-09 — 螢幕升級到 2.8 吋並修整體美觀

### 一句話

把舊的 0.96 吋小螢幕換成 **2.8 吋大螢幕**，整個操作畫面重畫，文字放大、中文字型升級，畫面切換感變順、不再有以前那種掃描閃爍。

### 你會看到什麼差異

1. **螢幕變大很多**：從原本郵票大小變成手掌心大小，遠遠就能看清倒數秒數。
2. **字級放大約 1.5 倍**：之前你反映過字看不清楚，這次主畫面字放大、間距重抓。
3. **中文字看起來更舒服**：「電擊」「給藥」這種筆畫密的字以前看起來歪歪的，現在換了字型工整很多。
4. **畫面切換不再閃**：以前切畫面會看到一條條掃描線像跑馬燈，現在切畫面接近瞬完成。
5. **操作流程跟線上 demo 一致**：13 個畫面（主選單、OHCA 倒數、待機、結束確認、6 秒通氣節奏…）都對齊 demo 的視覺，可以拿手機開 demo 並排對照。

### 硬體規格

| 項目 | 規格 |
|------|------|
| **顯示器** | 2.8 吋 TFT 彩色螢幕（型號 ST7789） |
| **解析度** | 320 × 240 像素 |
| **接線方式** | SPI 4-wire，運行頻率 80 MHz |
| **主控板** | ESP32-S3（GOOUUU N16R8，含 8MB PSRAM） |
| **功耗** | 典型 80 mA / 峰值 120 mA（含 TFT 背光） |
| **韌體佔用** | Flash 14.1%（約 470 KB / 3.34 MB）｜RAM 6.8%（22 KB / 320 KB） |
| **中文字型** | 自訂 24px 點陣字，222 個常用字含全形標點，91 KB |

### 過程中遇到並解決的問題

- 開機時主板上的 RGB LED 會亮一下白光（不影響功能但 PM 看了奇怪）— 已修，開機流程主動把 LED 關掉。
- 換螢幕後發現顯示驅動跟主板某顆 LED 共用同一條控制線 — 已重新分配腳位避開衝突。
- 第一版字級雖然放大但部分中文字（如「電擊」）筆畫密、看起來有歪斜感 — 換成自訂字型後解決。
- 螢幕切換每次都會看到掃描線往下跑 — 改用直接記憶體推送 (DMA) 整片送，現在切換接近瞬完成。
- 倒數時某些情境下按鍵會被連續觸發兩次 — 已修，按鍵防彈跳改用統一門檻。

## 3. MCP23017 規格與接線

### 為何選已焊排針版

PM 強項是韌體，硬體弱項。**選已焊排針版省下「焊 28 隻 pin」的工**，到貨直接插麵包板。

### 接線（接到 SparkFun Thing Plus ESP32-S3 的 Qwiic I2C）

| MCP23017 pin | → | ESP32-S3 | 備註 |
|---|---|---|---|
| VDD (9) | → | 3V3 | |
| VSS (10) | → | GND | |
| SDA (13) | → | GPIO 8（Qwiic SDA）| Wire bus 共用 |
| SCL (12) | → | GPIO 9（Qwiic SCL）| 同上 |
| RESET (18) | → | 3V3 | **不可浮接** |
| A0/A1/A2 (15/16/17) | → | GND × 3 | I2C 位址 = 0x20 |
| INTA (20) | → | 任一 GPIO | 5 顆按鈕中斷通知，省 polling |

**I2C pull-up**：Qwiic bus 已有 2.2kΩ 板載；走麵包板裸接時 SDA/SCL 各加 4.7kΩ pull-up 到 3V3。

### I2C 位址表（避衝突確認）

| 裝置 | 位址 | 來源 |
|---|---|---|
| MCP23017 | 0x20 | 新採購 |
| MAX17048 燃料計 | 0x36 | SparkFun 板載 |
| SH1106 OLED | 0x3C | 現行 |
| DS3231 RTC（Dev-Phase 3）| 0x68 | 預留 |

✅ 無衝突。

## 5. GPIO 重新分配（路徑 B 才需要）

對齊 PM #6「主鍵 / EPI / 電擊鍵保留本體 GPIO」：

| 按鍵 | 走哪 | 理由 |
|---|---|---|
| 主鍵（長按 3s OHCA 入口）| ESP32-S3 本體 GPIO | 救命路徑、零延遲 |
| EPI 鍵 | ESP32-S3 本體 GPIO | 倒數計時觸發要即時 |
| 電擊鍵 | ESP32-S3 本體 GPIO | 同上 |
| 上 / 下 | MCP23017 | 選單操作，慢 1ms 無感 |
| Power | MCP23017 | 長按關機 |
| 錄音 | MCP23017 | |
| 返回 | MCP23017 | |

**路徑 A 不需要這個改動**（GOOUUU 38 支 GPIO 全本體即可）。

## 6. 收貨驗收 SOP

### 6.1 電池（共用兩條路徑）

到貨當天執行，對齊 PM #5「接前驗極性」：

1. **三用電表量極性**
   - 紅探針碰電池接頭一邊、黑探針碰另一邊
   - **讀數正值 = 紅探針那邊是 +**
   - 確認紅線 = +、黑線 = -
2. **驗保護板**：短路兩極 < 0.5 秒，保護板應自動斷開（不會冒煙）
3. **量電壓**：3.6~4.2V 之間（出廠半電狀態）
4. **外觀**：無膨脹、無漏液、無破損

⚠️ **PH2.0 接頭極性沒有業界標準**，賣家文案「左紅右黑」**不能信，必須量**。如果極性對不上接收端模組，拆 JST 接頭塑膠外殼（小一字起子撥開卡榫）把紅黑線交換重插。

### 6.2 電池模組（路徑 A）

依 [`docs/power-module-purchase.md §4.2`](power-module-purchase.md) 既有 SOP 執行：
- 升壓電壓校正到 5.00V（PowerBoost 1000C 出廠 5.2V，可接受不必校）
- USB 插拔測試 pass-through
- 充電電流確認

### 6.3 開發板+電池模組（路徑 B）

1. USB-C 插上電腦：ESP32-S3 應自動進入 USB DFU 模式，可被 esptool 偵測
2. 接上 LiPo 電池：MAX17048 燃料計應透過 I2C 0x36 回傳電量
3. Qwiic 接頭量測 SDA/SCL 對 3.3V 應有 2.2kΩ pull-up
4. 板載 microSD 卡槽插卡測試讀寫

### 6.4 MCP23017 DIP-28

1. 麵包板插好，VDD/VSS 接 3V3/GND
2. SDA/SCL 接 ESP32 I2C
3. RESET 接 3V3（**這步漏掉會狂 reset**）
4. A0/A1/A2 接 GND（位址 0x20）
5. 跑 I2C scanner sketch，應在 0x20 看到回應

### 6.5 排針

無特殊驗收，焊接時注意對齊 90 度即可。

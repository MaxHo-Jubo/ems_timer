3.2　接地

下列所有 GND 全部焊接到同一個接地點（或同一條銅箔），不可鏈式串接、不可靠排針接觸：

  • 充電模組 OUT−（見上表，焊死）
  • TFT GND
  • DS3231 GND
  • 8 顆按鍵的共用回路
  • 蜂鳴器 −
  • 電量計（MAX17048）排針 GND 腳
3.3　上電前的兩道檢查（跳過任一件可能燒晶片）
  1. 校壓：充電模組先不要接到 ESP32。插上電池（或 Type-C），用電表量 OUT+ 對 OUT−，必須是 5.00V ± 0.05V。若不是，請用模組上的電位器調到 5.00V。
  2. 確認接的是 V5IN 不是 3V3：接好後再量一次 ESP32 的 V5IN 對 GND ≈ 5V、3V3 對 GND ≈ 3.3V。帶上 TFT 之後 V5IN 不可低於 4.7V，否則主控會反覆重開機。

5電量計（MAX17048）：本次不焊，只留排針

電量計使用 MAX17048 模組（I2C 位址 0x36），模組後續另行安裝。請在板上焊一組 5-pin 2.54mm 母排針（焊死在板上，不是留線），接法如下：

2　SCLGPIO 41與 DS3231 SCL 並聯，接 MAX17048 的 SCL

📌 產測韌體會掃描這組排針對應的位址 0x36。MAX17048 尚未插上、排針空著時畫面顯示 GAUGE 0x36: NOT FITTED，這是正確結果，不影響 PASS。
6必讀注意事項
  1. 充電模組 OUT+ 只能接 V5IN。接到 3V3 腳會直接燒掉主控晶片，且無法修復。
  2. OUT− 與所有 GND 必須焊接到同一點。不可用排針、杜邦線、鏈式串接。這個接點接觸不良會造成螢幕白屏，且不易排查。
  3. 下列腳位絕對不可使用（即使佈線上不方便）：
    GPIO 35 / 36 / 37（模組內部記憶體用，接上會當機）、48（板載 LED）、0 / 45 / 46（開機模式腳）、8～13（內建 Flash）、19 / 20（USB）、26～32。
    只用本文件列出的腳位，其他一律空著。
  4. 先校壓再接主控（§3.3）。OUT+ 必須 5.00V ± 0.05V。校完之後不要再動電位器。
  5. 按鍵不加外部電阻，蜂鳴器不加電阻與電晶體，I2C 不另加上拉。請依表格接線即可，額外加上的零件會改變韌體行為。
  6. TFT 的 SDO / MISO 與觸控腳全部不接。
  7. 開發板的 USB-C 口、BOOT 鍵、RST 鍵必須保持可操作，燒錄與重開機都靠它們。固定開發板時不要擋住。
  8. USB 與電池可以同時接（燒錄時需要），但前提是第 4 條校壓已完成。OUT+ 與 USB 的 5V 在板上是同一條軌，OUT+ 校太高會回灌 USB。
  9. 先焊接、再量測、最後才上電。順序：焊接完成 → 校壓（§3.3 第 1 條）→ 接 V5IN／GND → 量 V5IN 與 3V3（§3.3 第 2 條）→ 插 USB 燒產測韌體 → 看畫面。
7產測韌體與驗收步驟
7.1　燒錄包內容
檔案用途
firmware-merged.bin產測韌體（bootloader + 分割表 + 程式三合一）
flash.sh / flash.batmacOS／Linux 與 Windows 一鍵燒錄腳本

7.2　步驟
  1. 完成 §3.3 兩道檢查。
  2. 用 USB-C 線接開發板到電腦，執行 flash.sh（或雙擊 flash.bat），依提示選擇 port。若卡在「Failed to connect」：按住 BOOT → 按一下 RST → 放開 BOOT → 重新執行燒錄腳本。
  3. 燒錄完成後按一下 RST。螢幕先顯示 紅／綠／藍／白四色彩條約 1.5 秒，蜂鳴器響一短聲，接著進入狀態畫面。第一次上電時最後一列通常是 WAITING POWER CYCLE，RTC 第二行顯示 BACKUP: POWER CYCLE TO VERIFY。
  4. 斷電驗證鈕扣電池：拔掉 USB 線、拔掉電池 JST，讓板子完全沒電 10 秒，再接回電源開機。RTC 第二行應變成 BACKUP OK；若出現 FAIL: RTC BATTERY，代表 CR2032 沒裝或沒電。按 RST 不算斷電（斷電不到 5 秒），畫面會維持 WAITING POWER CYCLE。每台機器至少要做一次本步驟。
  5. 依 §4.3 的順序逐顆按下 8 顆按鍵，順序不可錯。每按一顆，畫面上該鍵由 [ ] 變 [x]，同時蜂鳴一短聲。按錯順序會直接 FAIL: BUTTON ORDER、兩顆同時觸發會 FAIL: BUTTON SHORT，按 RST 重新來過（RST 後不需再斷電）。
  6. 8 顆全部打勾且其他項目正常時，最後一列變成 PASS，蜂鳴器響兩長聲。
🚨 任何 FAIL 都會鎖住畫面，修正接線後按 RST 重測。斷電驗證（步驟 4）只需做一次，RST 之後不用重做。

7.5　FAIL 原因對照
畫面意思先檢查
FAIL: I2C BUS STUCKSDA 或 SCL 被拉住，整條 I2C 不通GPIO 41／42 是否短路到 GND 或互接；DS3231 GND 是否接妥；是否多接了上拉電阻
FAIL: I2C BUS ERROR code NI2C 回傳非預期的錯誤碼SDA／SCL 焊點是否虛焊、線是否過長或與電源線綑在一起
FAIL: NVS ERROR主控板內部儲存讀寫失敗與焊接無關，換一片開發板再試；仍出現請聯絡
FAIL: RTC MISSINGDS3231 沒有回應（曾經有一次沒回應也算，虛焊會這樣）VCC 是否接 3V3、SDA／SCL 是否接反（SDA=42、SCL=41）、模組焊點
FAIL: RTC I/O ERRORDS3231 有回應但暫存器讀寫失敗或讀到亂資料SDA／SCL 焊點、VCC 是否穩定在 3.3V、是否誤接 5V
FAIL: RTC NOT TICKINGDS3231 讀得到但時間不走模組晶振是否受損、VCC 是否穩定
FAIL: RTC BATTERY斷電再上電後 DS3231 失憶CR2032 是否已裝、極性、電池座彈片是否接觸
FAIL: BUTTON ORDER exp N got M預期第 N 顆卻按到第 M 顆第 N、M 顆按鍵是否接反 GPIO（對照 §4.3）
FAIL: BUTTON SHORT N+M兩顆按鍵同時觸發第 N、M 顆的 GPIO 線是否短路
螢幕全白或全黑TFT 沒收到訊號或沒電OUT− 是否焊死（§3）、VCC 是否在 V5IN、5 條 SPI 線對照 §4.1
某顆按鍵按了不打勾該鍵沒接通該鍵的 GPIO 與 GND 兩腳、按鍵本身導通
按了打勾但沒聲音蜂鳴器沒接通或極性反GPIO 14 與 GND、蜂鳴器 + / − 方向

Phase 邊界時序

關鍵測試案例

  • A1.2COUNTDOWN: since=180000 → display_remaining=60000，仍未轉 WARNING
  • A1.3邊界 since=180001 → 應已轉 WARNING（外層狀態機決定）
  • A1.4WARNING since=180001 / 195001 → 每 15s 短嗶 + 黃慢閃

  • A1.7邊界 since=245000 還在 ALARMING；245001 轉 OVERTIME
  • A1.8OVERTIME：display_remaining 改顯示累計時間，每 15s 嗶

WARNING→≥240s → ALARMING

12高風險區與排程
高風險區（必驗）
⚠ EPI 倒數精度 ±50ms
RTOS 下不易保證；任何延遲影響救護現場 4 分鐘節奏。
獨立 FreeRTOS task + 高優先級；L3 用碼錶與 OLED 對拍
⚠ EPI 高優先打斷通氣（≤50ms 靜音）
vent overlay → ALARMING 切換延遲超標會誤導救護人員。
vent task 低優先；L3 高速攝影驗證
⚠ 補登資料不可變
UI 層誤觸或工程繞過會破壞紀錄可信度（V1 §9.7 / §23.3）。
韌體層拒絕 API；L1 釘住「補登成立後嘗試修改」一定 fail
⚠ LittleFS 寫入中拔電 → 檔案毀損
案件資料丟失或讀取失敗。
atomic rename + fsync；L3 拔電壓力測試 50 次
⚠ BLE 中斷重傳狀態不一致
App 端可能重複收錄同案件。
整筆重傳 + Case ID 去重；L2 mock 中斷模擬
⚠ 系統音量不可靜音
UI 滑桿越界導致 0 音量會錯失警報（V1 §23.6）。
韌體層拒絕 0；L1 釘住
⚠ millis() rollover（49.7 天後）
uint32 wrap 後計時錯誤。
所有時間運算用 uint32 減法（rollover-safe）；L1 釘住 wrap-around case

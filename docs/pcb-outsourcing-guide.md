## 1. 為什麼要外包

### 1.1 PCB layout 是高度經驗依賴的工作

- EMI/EMC（電磁相容）走線經驗
- 高速訊號（USB 2.0、I2S 時脈）阻抗匹配
- 電源平面切割、地迴路設計
- 量產良率考量（焊盤、silkscreen、組裝公差）
- DFM（Design for Manufacturing）/ DFT（Design for Test）

### 1.2 自做的成本

從零學 KiCad 到能量產：**保守估計 2~3 個月**，且可能踩坑要重打樣（每次打樣 NT$2k~10k + 2 週工期）。

### 1.3 機會成本

- 我（PM/開發者）的優勢：**懂韌體 + 懂使用情境**
- PCB layout 不是核心競爭力
- 錢付給專業的，時間花在驗證功能 / App / 業務拓展

## 2. 該外包什麼、不該外包什麼

### 2.1 ✅ 外包項目

| 項目 | 說明 |
|------|------|
| Schematic 落圖 | 把設計轉成 KiCad / Altium 檔 |
| PCB layout | 擺零件、走線、生 Gerber |
| DFM 檢查 | 製造可行性審查 |
| 打樣對接 | 直接送嘉立創 / 合泰 / 欣興 |
| BOM 採購對接 | 部分廠商可代採料 |
| SMT 貼片 | 小批量打樣含 PCBA |

### 2.2 ❌ 不該外包（自己掌握）

| 項目 | 為什麼自己做 |
|------|-------------|
| BOM 選料 | 廠商會推銷他們熟的料，你要自己決定（成本 / 替代 / 供應鏈） |
| 電源樹架構 | 用什麼 PMIC、電池規格、續航目標 |
| 腳位分配（GPIO） | 韌體已經跑在某些 GPIO 上，動了要重測 |
| 韌體驗證 | 拿到打樣板自己燒測，廠商不懂你的業務邏輯 |
| 認證需求決策 | FCC/NCC/CE 要不要做、預算多少 |
| 機構尺寸 | 與外殼設計綁定，影響 PCB 外型 |

|------|------|

| 優勢 | 速度快、價格透明、台灣本土可簽 NDA |
| 風險 | **報價可能不含 schematic 落圖、SMT、DFM**；服務標準化、客製空間小 |

## 4. 外包前必備清單（7 項）

> **這 7 項做齊，外包商就能無痛接手，報價也會精準。**
> 沒準備好就發包，等於錢白花、來回拉鋸。

### 4.1 完整 BOM
- 主料號（Mfr Part Number）
- 封裝（SMD/DIP，e.g. 0402 / SOT-23 / QFN-32）
- 替代料（至少 2 家供應商）
- 單價與最小起訂量（MOQ）
- 預估壽命（停產風險）

### 4.2 腳位分配表（GPIO Pin Assignment）
- 哪顆 GPIO 接哪個外設
- 衝突檢查（同一腳不能同時做兩件事）
- I2C / SPI / I2S / UART 匯流排規劃
- ADC / 中斷腳位需求

### 4.3 電源樹架構圖
- USB-C 5V 輸入 → 充電 IC → 電池
- 電池 → BMS（過充 / 過放保護）
- BMS → DCDC / LDO → 3.3V / 1.8V 軌
- 各模組消耗預估（mA）

### 4.4 各模組接線清單（Netlist）
- 模組對模組的訊號連接
- 重要訊號的特殊需求（差動對 / 阻抗控制）

### 4.5 機構尺寸圖
- PCB 外型尺寸（依概念圖約 78×95mm 範圍）
- 按鈕 / USB / OLED / 麥克風開孔位置
- 螺絲孔 / 卡榫 / 測試點預留
- 與外殼的高度限制（28mm 厚度內）

### 4.6 認證需求
- FCC / NCC / CE / BSMI 是否需要？
- 是否要過醫療電氣安規（EN 60601）？
- 影響 layout（隔離距離、爬電距離、ESD 保護）
- 預算與時程（NCC NT$5~15 萬、6~8 週）

### 4.7 量產數量預估
- 打樣（1~5 片）→ 試量產（50~100 片）→ 量產（≥500 片）
- 不同階段的 BOM 採購策略不同
- 影響選料（量小選現貨、量大可選封裝特殊或停產風險高的料）

## 6. 風險與注意事項

### 6.1 智財保護
- 簽 NDA（保密協議）再交付完整資料
- 醫療相關設計避免送中國代工（資料外洩風險）
- Schematic / Gerber 保留版本控制（git）

### 6.2 驗收標準
- 要求對方提供 ERC（電氣規則檢查）/ DRC（設計規則檢查）報告
- 要求 3D 視圖 / 機構對位確認
- 打樣後保留 BOM 與 Pick & Place 檔案備查

### 6.3 不要 Phase 4 才開始準備
- 量產 PCB 一旦定版，硬體就固化
- 任何沒驗證的模組翻車（例如 INMP441 靈敏度不足），就是整批板子報廢
- **量產前必須跑完 Phase 1.5 / 2 / 3 / Phase A~H**

### 6.4 預算規劃（粗估）

| 項目 | 預算（NT$） |
|------|------------|
| Schematic + PCB layout 外包 | 30,000 ~ 80,000 |
| 打樣（1~3 片，含 SMT） | 5,000 ~ 20,000 |
| 認證測試（NCC） | 50,000 ~ 150,000 |
| 外殼開模（射出，量產才需要） | 100,000 ~ 500,000 |
| 試量產（50~100 片） | 30,000 ~ 100,000 |
| **合計（量產前）** | **約 NT$ 22 萬 ~ 85 萬** |

### 9.1 試算前提（依目前 BOM 草稿）

| 項目 | 數值 |
|------|------|
| Smd Pad 數量（粗估） | 約 300 |
| Dip Pad 數量 | 約 15 |

| 焊點噴鍍 | 無鉛噴錫（醫療用建議 RoHS） |

| 板材 | 無指定（FR-4） |

### 9.2 報價結果

| PCB 層數 | Layout 費用 | 打樣 10 片 | 小計 | 與雙層差額 |
|:---:|:---:|:---:|:---:|:---:|
| 雙層 | NT$8,940 | NT$1,800 | **NT$10,740** | — |
| 四層 | NT$10,155 | NT$2,300 | **NT$12,455** | +NT$1,715 |

### 9.3 判斷

**價格落點**：NT$28/pad，遠低於台灣行情（NT$50~150/pad）。
**含意**：自動報價系統、走量化作業、**很可能不含 schematic 落圖與 SMT 貼片**，需向廠商確認。

### 9.4 ⭐ 建議選 4 層板（多 NT$1,715）

| 面向 | 雙層 | 四層 |
|------|------|------|
| **GND 平面完整性** | 走線切割地，BLE 訊號受影響 | 整層 GND，乾淨 |
| **BLE 天線表現** | 容易受干擾、距離縮短 | 訊號穩定、距離可達標 |
| **USB-C 高速訊號** | 阻抗不易控制 | 容易做 90Ω 差動 |
| **78×95mm 箱內走線** | 擁擠、容易繞不開 | 寬鬆 |
| **EMI / NCC 認證** | 容易 fail，要重打樣 | 通過率高 |
| **電源完整性** | 共用走線，有雜訊 | 獨立電源層 |

省 NT$1,715 = 換來週級別 debug 痛苦或 NCC 認證 fail 重做（每次 NT$5~15 萬），帳很好算。

## 附錄 A：MCP / Plugin 現況

**結論：目前沒有成熟的 MCP 可以直接畫電路圖。**

電路設計是視覺化 + 拓樸關係的工作，純文字 LLM 不適合。實際工具：
- KiCad（開源、業界標準、有 Python API，仍需人工拖拉）
- EasyEDA（線上 + 嘉立創整合，量產對接最快）
- Altium（商業、量產廠常用）

**Claude / AI 能做的**：BOM、腳位分配、電源樹、接線清單、設計評審 checklist 等**純文字產出**。
**Claude / AI 不能做的**：直接產出 .kicad_sch / PCB layout / Gerber。

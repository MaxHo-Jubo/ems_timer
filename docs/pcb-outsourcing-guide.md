## 1. 為什麼要外包

### 1.1 PCB layout 是高度經驗依賴的工作

- EMI/EMC（電磁相容）走線經驗
- 高速訊號（USB 2.0、I2S 時脈）阻抗匹配
- 電源平面切割、地迴路設計
- 量產良率考量（焊盤、silkscreen、組裝公差）
- DFM（Design for Manufacturing）/ DFT（Design for Test）

### 1.2 自做的成本

從零學 KiCad 到能量產：**保守估計 2~3 個月**，且可能踩坑要重打樣（每次打樣 NT$2k~10k + 2 週工期）。

### 1.3 機會成本

- 我（PM/開發者）的優勢：**懂韌體 + 懂使用情境**
- PCB layout 不是核心競爭力
- 錢付給專業的，時間花在驗證功能 / App / 業務拓展

## 2. 該外包什麼、不該外包什麼

### 2.1 ✅ 外包項目

| 項目 | 說明 |
|------|------|
| Schematic 落圖 | 把設計轉成 KiCad / Altium 檔 |
| PCB layout | 擺零件、走線、生 Gerber |
| DFM 檢查 | 製造可行性審查 |
| 打樣對接 | 直接送嘉立創 / 合泰 / 欣興 |
| BOM 採購對接 | 部分廠商可代採料 |
| SMT 貼片 | 小批量打樣含 PCBA |

### 2.2 ❌ 不該外包（自己掌握）

| 項目 | 為什麼自己做 |
|------|-------------|
| BOM 選料 | 廠商會推銷他們熟的料，你要自己決定（成本 / 替代 / 供應鏈） |
| 電源樹架構 | 用什麼 PMIC、電池規格、續航目標 |
| 腳位分配（GPIO） | 韌體已經跑在某些 GPIO 上，動了要重測 |
| 韌體驗證 | 拿到打樣板自己燒測，廠商不懂你的業務邏輯 |
| 認證需求決策 | FCC/NCC/CE 要不要做、預算多少 |
| 機構尺寸 | 與外殼設計綁定，影響 PCB 外型 |

## 4. 外包前必備清單（7 項）

> **這 7 項做齊，外包商就能無痛接手，報價也會精準。**
> 沒準備好就發包，等於錢白花、來回拉鋸。

### 4.1 完整 BOM
- 主料號（Mfr Part Number）
- 封裝（SMD/DIP，e.g. 0402 / SOT-23 / QFN-32）
- 替代料（至少 2 家供應商）
- 單價與最小起訂量（MOQ）
- 預估壽命（停產風險）

### 4.2 腳位分配表（GPIO Pin Assignment）
- 哪顆 GPIO 接哪個外設
- 衝突檢查（同一腳不能同時做兩件事）
- I2C / SPI / I2S / UART 匯流排規劃
- ADC / 中斷腳位需求

### 4.3 電源樹架構圖
- USB-C 5V 輸入 → 充電 IC → 電池
- 電池 → BMS（過充 / 過放保護）
- BMS → DCDC / LDO → 3.3V / 1.8V 軌
- 各模組消耗預估（mA）

### 4.4 各模組接線清單（Netlist）
- 模組對模組的訊號連接
- 重要訊號的特殊需求（差動對 / 阻抗控制）

### 4.5 機構尺寸圖
- PCB 外型尺寸（依概念圖約 78×95mm 範圍）
- 按鈕 / USB / OLED / 麥克風開孔位置
- 螺絲孔 / 卡榫 / 測試點預留
- 與外殼的高度限制（28mm 厚度內）

### 4.6 認證需求
- FCC / NCC / CE / BSMI 是否需要？
- 是否要過醫療電氣安規（EN 60601）？
- 影響 layout（隔離距離、爬電距離、ESD 保護）
- 預算與時程（NCC NT$5~15 萬、6~8 週）

### 4.7 量產數量預估
- 打樣（1~5 片）→ 試量產（50~100 片）→ 量產（≥500 片）
- 不同階段的 BOM 採購策略不同
- 影響選料（量小選現貨、量大可選封裝特殊或停產風險高的料）

## 6. 風險與注意事項

### 6.1 智財保護
- 簽 NDA（保密協議）再交付完整資料
- 醫療相關設計避免送中國代工（資料外洩風險）
- Schematic / Gerber 保留版本控制（git）

### 6.2 驗收標準
- 要求對方提供 ERC（電氣規則檢查）/ DRC（設計規則檢查）報告
- 要求 3D 視圖 / 機構對位確認
- 打樣後保留 BOM 與 Pick & Place 檔案備查

### 6.3 不要 Phase 4 才開始準備
- 量產 PCB 一旦定版，硬體就固化
- 任何沒驗證的模組翻車（例如 INMP441 靈敏度不足），就是整批板子報廢
- **量產前必須跑完 Phase 1.5 / 2 / 3 / Phase A~H**

### 6.4 預算規劃（粗估）

| 項目 | 預算（NT$） |
|------|------------|
| Schematic + PCB layout 外包 | 30,000 ~ 80,000 |
| 打樣（1~3 片，含 SMT） | 5,000 ~ 20,000 |
| 認證測試（NCC） | 50,000 ~ 150,000 |
| 外殼開模（射出，量產才需要） | 100,000 ~ 500,000 |
| 試量產（50~100 片） | 30,000 ~ 100,000 |
| **合計（量產前）** | **約 NT$ 22 萬 ~ 85 萬** |

## 11. 量產零件對映與設計注意事項（2026-09-06）

> 回答一個常被問的問題：「量產是不是零件都要換？」——**不是換零件，是把模組拆開只留晶片，全部放到一片自己的 PCB 上。**
> 晶片大多不換，換的是形式：麵包板、杜邦線、開發板、各家模組小板全部消失。
> 本節依 2026-09-06 麵包板現況（`hardware-procurement-v2.md` §0 快照表、`gpio-allocation.md` 速查表）整理。

### 11.1 兩層工作：原理圖決定誰接誰，佈線把它變成銅箔

| 層 | 內容 | 誰做 | 對應現況 |
|---|---|---|---|
| **原理圖（Schematic）** | 每條連線是一個「網路」，列出它連到哪些晶片腳、哪些電阻電容 | **自己**（§2.2） | `gpio-allocation.md` 速查表 + 各模組接線表，就是原理圖的文字版 |
| **PCB 佈線（Layout）** | 把網路變成走線、過孔、銅箔平面；零件擺位、外型、鑽孔 | 外包（§2.1） | 杜邦線 → 走線；麵包板電源軌 → 整層 GND 平面 |

原理圖那一層的內容**必須跟現在韌體跑的腳位一模一樣**，改一支腳韌體就要重測。舉例，今天麵包板上「MAX17043 SDA → 杜邦線 → GPIO 42」在原理圖裡是：

```
網路 I2C_SDA：ESP32-S3-WROOM-1 GPIO42、DS3231 SDA、MAX17048 SDA、R? 4.7k → 3V3
網路 I2C_SCL：ESP32-S3-WROOM-1 GPIO41、DS3231 SCL、MAX17048 SCL、R? 4.7k → 3V3
網路 GND   ：所有晶片 GND 腳、電池負極、USB-C 外殼
```

你現在用的每一片模組，本來就是別人畫好的縮小版：晶片＋幾顆電阻電容＋排針。量產只是自己畫一片、把它們合併。

### 11.2 零件對映表（麵包板 → 量產板）

| 麵包板現況 | 量產板上 | 晶片 | 備註 |
|---|---|---|---|
| GOOUUU ESP32-S3 開發板（N16R8） | **ESP32-S3-WROOM-1-N16R8** 模組直接貼板 | 不換 | 開發板上的 LDO、USB 電路、WS2812 全部變成自己的設計；GPIO 48 因 WS2812 消失而釋出；模組本身已有 NCC/FCC/CE，省掉射頻模組認證那一段；N16R8 的 GPIO 35/36/37 仍不可用 |
| 2.8" TFT 模組（ST7789，帶 LDO） | **裸 ST7789 面板**，FPC 座接主板 | 不換 | 面板 3.3V 直驅，**5V 需求消失**；背光電流由自己的電路供 |
| DS3231 模組（ZS-042 類） | DS3231 晶片 + CR2032 座（或超級電容） | 不換 | 模組附掛的 AT24C32（0x57）、模組上拉、充電二極體一起消失 |
| MAX17043 模組（SparkFun V1.1 複刻） | **MAX17048** 晶片 | 換型號 | VDD 與 CELL 分開：VDD 與 I2C 上拉接 3V3，CELL 感測電池。**2026-09-06 踩的「上拉接電池電壓、GPIO 41/42 達 4V」在原理圖那一行就解掉**；換算常數見 `power-module-purchase.md §10.8` |
| 聯騰 TP4056 一體板（TP4056+DW01+8205A+SX1308） | TP4056+DW01A+FS8205A，**或**一顆帶 power-path 的充電 IC（如 BQ24074 類） | 可換 | 帶 power-path 的 IC 一次解掉「USB 與電池同接誰出力」，即 `hardware-procurement-v2.md` #10 PowerBoost 想驗證卻沒驗的 load-sharing |
| SX1308 5V 升壓 | **很可能不需要** | 拿掉 | 5V 只為了 TFT 模組；改裸面板後系統只剩 3.3V 軌，見 §11.3 |
| 8 顆無段開關 | 板上 tact switch + 外殼按鍵帽 | 不換 | 主按鍵紅色大鍵可改面板安裝式；按鍵線若外露要加 ESD |
| 主動蜂鳴器 GPIO 直驅 | 蜂鳴器 + 電晶體 + 飛輪二極體 | 不換 | 現況「GPIO 兼作供電」不是量產寫法；驅動極性可能反轉，韌體要對一次 |
| USB-C（由開發板提供） | USB-C 座 + CC 腳 5.1k 下拉 ×2 + ESD 保護（USBLC6 類） | 新增 | 開發板替你做掉的部分；CC 下拉沒接，USB-C 對 USB-C 線不會給電 |
| 麵包板、杜邦線、Y 分接線 | 沒有 | 消失 | 2026-09-06 量到的 4~20Ω 地線接點問題整類消失 |
| INMP441 / MicroSD / 震動馬達 | 依 SoT V1 §2.2 不在 V1 範圍 | 保留腳位 | 只在原理圖預留腳位與焊盤，不上料，見 `gpio-allocation.md §5` |

焊接現實面：ESP32-S3-WROOM-1 是半孔封裝還能手焊；**MAX17048 是 2mm 見方 TDFN、焊盤在肚子底下，手焊不實際**，打樣就要含 SMT（§2.1、§10 Q4）。

### 11.3 電源樹簡化建議

現況是「電池 → SX1308 升到 5V → 開發板 LDO 降到 3.3V」兩級，中間一堆地線回流；量產板建議收成**一條 3.3V 軌**：

```
USB-C 5V ──┐
           ├─ 充電 IC（含 power-path）─┬─ 電池 3.0~4.2V（DW01A/FS8205A 保護）
           │                          │
           └──────────────────────────┴─ buck-boost（TPS63020 類）─ 3.3V ─ ESP32 / TFT / DS3231 / MAX17048
```

- buck-boost 而非 LDO：ESP32-S3 峰值數百 mA，LDO 在電池掉到 3.5V 以下就進 dropout，會浪費電池最後兩成
- 一條軌的好處：拿掉升壓、拿掉 LDO 級聯、拿掉「6V 誤調回灌 USB」這類事故的物理路徑（2026-09-05 事件）
- 功耗預算與續航估算沿用 SoT V1 §20.4，改拓樸後重算一次

### 11.4 模組替你藏起來、量產要自己畫的電路

- 每顆 IC 電源腳旁至少一顆 0.1µF 去耦電容，晶片 datasheet 有指定值就照它
- **I2C 上拉只留一組**（4.7k 或 10k）接 3V3；DS3231、MAX17048 模組上各自那組不再存在
- ESP32-S3-WROOM-1 天線端的板子要挖空或淨空，銅箔不可壓在天線下方，依模組 datasheet 的 keep-out 尺寸
- USB-C：CC1/CC2 各 5.1k 到 GND、D+/D− 走差動對（4 層板才好做 90Ω，§9.4）、TVS
- 電池：接頭防呆（PH2.0 有方向性，但焊盤要標極性）、反接保護、保護板不可被旁路（見 §11.5 第 3 條）
- 蜂鳴器與任何感性負載：電晶體驅動 + 飛輪二極體
- **測試點**：每條重要網路留裸露焊盤給 Pogo Pin 治具（燒錄 USB、3V3、GND、I2C、按鍵、蜂鳴器）
- 序號與燒錄：保留 USB 燒錄路徑（native USB-JTAG，`CLAUDE.md` Prod-Phase 燒錄策略），partition 已含 OTA

### 11.5 從麵包板帶進原理圖的設計規則（2026-09-05～06 實測教訓）

| # | 規則 | 來源 |
|---|---|---|
| 1 | I2C 上拉電阻接的電源 domain 必須等於 MCU 的 IO 電壓；任何「上拉接電池」的模組一律不進量產 BOM | MAX17043 V1.1 模組 2.2kΩ 接電池，GPIO 41/42 實測 4V，超 ESP32-S3 VIH 上限 VDD+0.3V |
| 2 | 地線走整層 GND 平面，不允許鏈式回流；每個模組的 GND 直接落到平面 | 麵包板電源軌接點 4~20Ω，負載 200mA 就是 0.8V 偏移，超過 MAX17043 VIL 0.5V |
| 3 | 電池負極只經保護 FET 到系統地，**不得有任何旁路**（原型上 MAX17043 GND 同時接電池負極與 ESP32 GND，就是旁路） | `power-module-purchase.md §10.7` 結構隱患 |
| 4 | 每個 I2C slave 的診斷要能分「NACK（沒人在家）」與「timeout（在家但抓住 bus）」，韌體 log 印錯誤碼不吞 | `src_i2c_scan` 2026-09-06 改版；Error −1 vs 263 分出 MAX17043 晶片故障 |
| 5 | 電源模組電位器類可調輸出不進量產；量產電源軌用固定回授電阻 | 2026-09-05 TP4056 升壓誤調 6V 事件 |
| 6 | 任何從電池取電的 IC，其 I2C 腳在「電池拔掉」時不得把 bus 拖低 | V1.1 模組無電池時 2.2kΩ 變下拉，DS3231 一起讀不到；MAX17048 VDD 接 3V3 即免疫 |

### 11.6 原型完全沒有、量產一定要加的項目

| 項目 | 說明 | 參考 |
|---|---|---|
| 外殼 | 3D 列印撐到試量產；射出開模是最大一筆錢。按鍵、螢幕、USB 口位置從開模起不可再改，PCB 外型要先跟外殼定 | §4.5、§6.4 |
| 認證 | NCC 低功率射頻器材必要，用已認證模組減輕但不免除；鋰電池 BSMI 與運輸 UN38.3 待確認；**「救護計時器」是否屬醫療器材要與 PM／法規顧問確認**，這一條會改變整個成本結構 | §4.6 |
| 產線治具 | 燒錄 + 測試 Pogo Pin 治具；每台寫入序號；韌體加「產測模式」一次自檢按鍵、螢幕、蜂鳴器、RTC、燃料計 | `CLAUDE.md` Prod-Phase 燒錄策略 |
| 韌體對映層 | GPIO 表微調（GPIO 48 釋出）、蜂鳴器驅動極性、MAX17048 換算常數、關 debug log、序號寫入；功能邏輯不動 | `tasks/todo.md` T10 |

### 11.7 建議路徑：兩段式

1. **載板（carrier board）**：一片只有插座和走線的 PCB，把現有開發板、TFT 模組、DS3231 模組、電源模組、MAX17048 模組插上去，配 3D 列印殼。設計風險接近零，可自己用 KiCad 畫，幾千元打 5~10 片。目的：拿去現場試用、把規格改到不再改，同時徹底告別麵包板。
2. **整合板**：規格凍結後照 §5 流程外包 layout，4 層板（§9.4），走打樣 1~5 片 → 試量產 50~100 片 → 量產 ≥500 片（§4.7）。

理由：一人團隊最貴的不是打樣費，是規格改一次就重 layout 一次。

**Layout 完成後的自我驗收**：拿 Gerber 或 PDF 逐一對照 `gpio-allocation.md` 每一條網路、§11.5 每一條規則，確認過才打樣；一支腳畫錯，打樣板要等下一輪。

## 附錄 A：MCP / Plugin 現況

**結論：目前沒有成熟的 MCP 可以直接畫電路圖。**

電路設計是視覺化 + 拓樸關係的工作，純文字 LLM 不適合。實際工具：
- KiCad（開源、業界標準、有 Python API，仍需人工拖拉）
- EasyEDA（線上 + 嘉立創整合，量產對接最快）
- Altium（商業、量產廠常用）

**Claude / AI 能做的**：BOM、腳位分配、電源樹、接線清單、設計評審 checklist 等**純文字產出**。
**Claude / AI 不能做的**：直接產出 .kicad_sch / PCB layout / Gerber。

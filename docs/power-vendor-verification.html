🔴 本類兩家現階段都不建議接洽。翊嘉 ARCH 與力英 LTE 都是 AC-DC 領域，跟 EMS DoseSync Pro 走 LiPo + DC-DC 升壓拓樸不對口。Pilot 階段聯騰一體版 + PowerBoost 1000C 已能滿足需求，量產自製 PCB 後也是用 MCP73831 + TPS63802 等 IC 級方案，不需要找電源 ODM 廠。

6後續接洽時機建議

6.1 接洽前提條件（建議）

條件判準
聯騰 + PowerBoost pilot 驗證完成確認電源切換穩定、續航時數有實測數據
原型機外殼空間定型電池物理尺寸 / 接頭方向 / 線材走向都有具體規格
3.3V 全系統驗證跑完確定量產走拓樸 A（5V）還是拓樸 B（3.3V Buck-Boost）
MAX17048 燃料計 UX 決策PM 確認 UI 上要不要顯示電量百分比 / 剩餘時間
數量級預估PM 確認 pilot 量 + 量產年度需求

6.2 接洽時要帶的資料（pilot 完成後）

  • 電源拓樸最終決策（5V 或 3.3V buck-boost）
  • 實測耗電曲線（待機 / BLE TX / 倒數提醒峰值）
  • 電池尺寸實測（外殼空間扣完後的可用空間）
  • 數量分級預估（5 / 20 / 100 / 500 / 1000 台對應單價需求）
  • 目標上市時程（廠商評估產能配合度）
  • 需要的認證範圍（BSMI / UN38.3 / IEC62133 / CE，依 PM 決策）

6.3 對外切入語（沿用 PDF §5 策略）

📌 不要一開始講「醫療器材」，以免廠商因法規 / 責任 / 量產門檻而不願承接。建議用詞：「ESP32-S3 可攜式原型裝置」「小型可攜式裝置電源整合」。等廠商有意願接案後再評估是否討論認證需求。
